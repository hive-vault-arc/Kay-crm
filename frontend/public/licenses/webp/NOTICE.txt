Safari WebP encoding fallback

libwebp 1.6.0, WebM project / Google contributors, BSD licence and patent grant.
Only the encoder WASM and its generated wrapper are served.
The library reports version 1.6.0 (0x010600). No WebP decoder is exported.
Its input is bounded, already-decoded canvas RGBA pixels, not original files.
libwebp copyright/licence and patent grant: libwebp-COPYING.txt,
libwebp-PATENTS.txt. Source: https://github.com/webmproject/libwebp/tree/v1.6.0
Emscripten runtime notices: EMSCRIPTEN-LICENSE.txt.

The fallback runs in a disposable same-origin worker only when native canvas
WebP export is unavailable. Build/dev verifies exact source artifact hashes;
no runtime CDN or conversion provider is contacted. Native browser encoding
is preferred. The source library is unmodified. Our generated module exports
the public encoder/memory functions and a heap accessor; no dynamic JavaScript
evaluation or threads, with a 256 MiB heap ceiling. Files:
/webp/libwebp-1.6.0.js and /webp/libwebp-1.6.0.wasm
Build script and pinned Emscripten 4.0.23 toolchain:
https://github.com/hive-vault-arc/Kay-crm/blob/main/frontend/scripts/build-photo-codecs.sh
The separate versioned files can be replaced after the build with compatible
implementations; the application code is not relicensed.

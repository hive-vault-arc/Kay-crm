# Lead/Deal interface refinement

Mode: Operate. Repeated daily use by KAY agents/managers on authorized CRM
records. The owner confirms the IMMO World composition, existing KAY colours
and left-side filters, and explicitly adds create/edit forms to the scope.

## Direction contract

THESIS: Find and qualify client work without fighting the frame. Replace top
filter bars and broad outer empty bands, not the existing business workflow.

OWN-WORLD: Existing KAY light canvas, white surfaces, black navigation, gold
creation/selection and current semantic status colours. System sans, typed
Iconsax and shadcn/Tailwind controls remain. No new visual world or asset.

STORY: Scan the rich list, refine it from the left, open the record and act on
its client/project facts. Every field, private boundary, saved-history snapshot,
command and error recovery retains its actual current contract.

FIRST VIEWPORT: Full available workspace width with16px safe insets; compact
title/actions, a256px desktop filter rail and fluid table; below1280px, one
accessible left Sheet. Details pair factual panels at1280px; forms pair their
major sections only above1536px. Narrow screens stack, and only named tables
scroll horizontally. Edit actions are immediately findable in record headers.

FORM: Precisely requested existing-world refinement. Concept/seed/comp/QUALITY
BAR are N/A, not omitted. ENERGY1/RHYTHM1/MOTION1. Ordinary control feedback only.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance

Backend code/data, unrelated page geometry, authentication, actual qualification,
stock/finance/history semantics and KAY's approved assets remain untouched.
Verification uses isolated synthetic records, never captures actual local staff
credentials/client records, retains page errors as failures and preserves the
owner's AFTER timing for audit-only aesthetic findings. Existing metadata drift
is reported, not repaired outside this boundary.

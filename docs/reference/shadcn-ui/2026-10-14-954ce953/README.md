# shadcn/ui: offline documentation snapshot

Status: pinned upstream reference, not an installed KAY dependency  
Date: 2026-10-14  
Confirmed decision: KAY will use shadcn/ui for its Next.js interface.  
Open design choices: component base (Base UI, Radix, or React Aria), preset, colors, type, and icon set.  
References: [official documentation](https://ui.shadcn.com/docs), [official repository](https://github.com/shadcn-ui/ui), [Next.js installation guide](https://ui.shadcn.com/docs/installation/next), [KAY component guide](../../../04-design/ui-components.md).

The official shadcn/ui website does not publish a single versioned documentation archive. This snapshot preserves its English documentation source from repository commit [`954ce953412867a57b7e067c076fa7fd395ea115`](https://github.com/shadcn-ui/ui/tree/954ce953412867a57b7e067c076fa7fd395ea115), which was the `main` head collected on 2026-10-14. The npm registry reported `shadcn` CLI version `4.21.5` as `latest` at collection time. The CLI version and documentation commit are separate identifiers; this snapshot does not claim that they are a matched release.

## What is included

The upstream files retain their original repository layout under `apps/v4/`:

| Path | Contents |
|---|---|
| [`content/docs/`](apps/v4/content/docs/) | All 331 documentation-source files, including 316 MDX pages and navigation metadata |
| [`registry/`](apps/v4/registry/) | 1,514 component, block, chart, hook, and registry source files |
| [`examples/`](apps/v4/examples/) | 1,528 usage and preview source files |
| [`public/`](apps/v4/public/) | 951 local assets and published registry files used by the site |
| [`styles/`](apps/v4/styles/) | Upstream styles directory |
| [`components.json`](apps/v4/components.json), [`registry.json`](apps/v4/registry.json), and [license](LICENSE.md) | Site configuration examples and upstream MIT license |

These are original source files, not a built or runnable offline copy of the website. MDX pages use site-specific preview components, so a plain Markdown viewer will not render every demo. Some links still lead to online resources. The code and local assets remain available for inspection without installing anything in KAY.

## Navigate the documentation

Start with the [introduction](<apps/v4/content/docs/(root)/index.mdx>), then the [Next.js installation guide](apps/v4/content/docs/installation/next.mdx). The [components index](apps/v4/content/docs/components/index.mdx) is generated by the website; browse its [Radix](apps/v4/content/docs/components/radix/), [Base UI](apps/v4/content/docs/components/base/), and [React Aria](apps/v4/content/docs/components/aria/) directories offline, or use the [live component catalogue](https://ui.shadcn.com/docs/components) for rendered examples.

For setup and maintenance, see the [CLI commands](<apps/v4/content/docs/(root)/cli.mdx>), [`components.json` reference](<apps/v4/content/docs/(root)/components-json.mdx>), [theming and semantic tokens](<apps/v4/content/docs/(root)/theming.mdx>), and [registry guide](apps/v4/content/docs/registry/index.mdx). Component pages such as [Button](apps/v4/content/docs/components/radix/button.mdx), [Field](apps/v4/content/docs/components/radix/field.mdx), [Data Table](apps/v4/content/docs/components/radix/data-table.mdx), and [Sidebar](apps/v4/content/docs/components/radix/sidebar.mdx) show installation and composition patterns. The Data Table page is a guide to building a table, not a single ready-made `data-table` component.

The live site also offers [Blocks](https://ui.shadcn.com/blocks), [Charts](https://ui.shadcn.com/charts), and a [registry directory](https://ui.shadcn.com/docs/directory). The source for site blocks and charts is preserved in `apps/v4/registry/new-york-v4/`. Review any third-party registry code before adopting it.

Search locally from the KAY project root with `rg -n "term" docs/reference/shadcn-ui/2026-10-14-954ce953/apps/v4/content/docs`. This snapshot does not update automatically and should not be treated as KAY's final component or design-token specification.

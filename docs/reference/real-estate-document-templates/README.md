## Handoff pour l'implémentation suivante

Ces fichiers sont les références fournies par Khalid pour examiner la structure,
les champs et la mise en page avant de créer les exemples et gabarits du CRM.
Garder les originaux intacts et produire les exemples avec des données fictives.
Les modèles ne remplacent pas les contrats métier, les permissions ou les règles
de paiement, de commission et de réservation déjà établis dans le projet.

Le `LISEZ-MOI.txt` conserve les limites du lot, notamment le statut préparatoire
du document 07 et les validations professionnelles à obtenir avant un usage réel.
La présente tâche organise uniquement les références ; elle n'implémente pas leur
génération et ne les déclare pas prêtes à signer.

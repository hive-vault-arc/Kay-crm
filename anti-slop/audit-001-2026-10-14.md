## Decisions and evidence

- 240 px desktop rail and 1024 px collapse preserve workspace width; 16/24/32 px
  responsive gutters, 8/4 px rhythm, 6/10/14 px radius roles reuse KAY's geometry.
- One shared token adapter reads the root JSON. Standard controls come from shadcn;
  KAY shell, PageHeader, DataState and DataTable are scoped compositions.
- Custom CSS is limited to theme mapping, global focus/reduced-motion behavior and
  safe-area gutters. No parallel stylesheet or chart stack was introduced.
- System sans-serif avoids unlicensed font files and network font requests.
- The supplied raster logo remains reference material. The transparent technical
  favicon placeholder carries no invented KAY artwork.
- No destructive or permission-changing action exists in SP-01, so those business
  states are N/A. Invalid, disabled, loading, empty, error and recovery states were checked.
